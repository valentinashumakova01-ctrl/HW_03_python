# Books Scraper
Проект для автоматического сбора данных о книгах с сайта Books to Scrape.

## Цель проекта
Разработать систему для парсинга информации о книгах, включая:

Сбор данных с отдельных страниц книг
Автоматический обход всех страниц каталога
Сохранение результатов в файл
Подготовку к автоматическому ежедневному запуску
Функциональность

Парсинг данных книги: извлечение названия, цены, рейтинга, наличия, описания и дополнительной информации
Обход всех страниц: автоматический переход по страницам каталога
Сохранение результатов: возможность сохранения данных в текстовый файл
Обработка ошибок: устойчивость к сетевым ошибкам и проблемам с парсингом
Используемые библиотеки

requests - для HTTP-запросов
beautifulsoup4 - для парсинга HTML
schedule - для планирования автоматического запуска
pytest - для написания тестов
Инструкции по запуску

## Установка зависимостей
